# The apps

A tour of each application: what it is for, its screens, and where each feature is explained.

| | [Dwarfium Hub](hub.md) | [Dwarfium Lite](lite.md) | [Dwarfium Scope Archive](scope-archive.md) |
|---|---|---|---|
| **In one line** | Installs, updates, starts, synchronizes | Drives the Dwarfs | Archives, explores, processes, plans |
| **Talks to the Dwarf** | Only to identify it | Wi-Fi (live API), Bluetooth | USB, FTP, MTP (files) |
| **Port** | — (its own window) | 8090 | 8080 |
| **Needs to stay running** | To watch the apps | For programs, end of night | During transfers |
| **Source** | [dwarfium-hub](https://github.com/stevejcl/dwarfium-hub) | [astro_dwarf_session](https://github.com/stevejcl/astro_dwarf_session) | [dwarfium-scope-archive](https://github.com/stevejcl/dwarfium-scope-archive) |

All three run on Windows, macOS and Linux, in English and French (Scope Archive's help also in German and Spanish).
